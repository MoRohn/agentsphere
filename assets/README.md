# Assets

Hand-drawn SVG for the guide. Each file paints its own dark background so it reads on GitHub's light and dark themes.

| Path | What it is |
| --- | --- |
| [logo.svg](logo.svg) | Mark. Wireframe sphere, three linked nodes. 256×256. |
| [banner.svg](banner.svg) | README hero. The orbit glyph sits between `agent` and `sphere`. |
| [sections/](sections/) | Openers for sections 00–09. 1200×240. |
| [diagrams/](diagrams/) | Architecture figures. Each has a Mermaid twin. See [the atlas](../docs/diagrams.md). |

Palette and the rules that keep a new figure on-system: [style guide](../docs/style-guide.md).

Do not add scripts, external images, or `foreignObject` to these files. GitHub renders them as images and will drop anything that looks like active content.
