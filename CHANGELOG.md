# Changelog

The guide version tracks the distilled pages. The bookmark count tracks the raw seed. Dates are the day the change landed in this repository.

## 0.1.0 — 2026-10-10

First public version of agentsphere.

- Added the field-guide structure: foundations, patterns, tools and MCP, prompting and skills, multi-agent orchestration, runtime, evals, security, case studies, and playbooks.
- Added four learning paths: Explorer, Builder, Operator, and Power user.
- Distilled ten X bookmarks dated 8–10 October 2026. Claims from those posts are marked **per post** and linked.
- Added hand-drawn logo, banner, section art, and architecture diagrams under `assets/`.
- Added Mermaid twins for the agent loop, wiki memory, MCP, gateway routing, phased orchestration, cloud and local runs, the security loop, and the guide's own knowledge flow.
- Recorded the repeatable update process in `CONTRIBUTING.md` and `sources/ADDING_BOOKMARKS.md`.
- Evals is a working primer. None of the seed bookmarks are evaluation posts, so that section is waiting for the next sources.
