## The situation

[@N01ennn](https://x.com/N01ennn/status/2108182955671580771) lists twenty GitHub names and says the stack is a model writing code, a skill setting timing and camera, and an engine rendering an MP4. The post attributes the list to Netflix engineers and aims it at Opus 5.5. [@himanshubuildss](https://x.com/himanshubuildss/status/2108540618553356666) lists ten resources for building sites with AI, and tells the reader to copy a prompt into Claude, Cursor, or Lovable.

## Claims worth isolating

| Claim | Status |
| --- | --- |
| The one-line stack: model, skill, engine | Per post, and a useful established split even if the credits are wrong |
| Netflix engineers posted the twenty repos | Per post. Unverified here |
| Built for, or demonstrated on, Opus 5.5 | Per post |
| [claude-motion](https://github.com/whaleyxbt/claude-motion) is the first repo | This guide links this URL. The other nineteen links in the post were not expanded |
| Check each repo before you install | Per post, and good advice regardless |
| scrolltide.co is the first of the ten site resources, with the post's asset counts | The domain was resolved. The counts are per post |
| The other nine site links | Only inside the post |

Names and blurbs for all twenty, and descriptions for all ten, are on the [concept page](../03-prompting-skills/creative-toolkits.md). They are not repeated here so the two pages cannot drift in opposite directions.

## What to steal

One engine, one skill, one reference. Read them before an install script runs. The [craft playbook](../09-playbooks/skills-and-craft.md) is that sequence.

## What to leave

A blanket `npx` of every name in the thread. The GSAP line in the post mentions `npx skills add greensock/gsap-skills`. That is a command the post printed, not a command this guide is telling you to run sight-unseen.
