# Creative toolkits

Two posts are catalogs: twenty motion repositories, and ten libraries for building websites with an agent. This page keeps their lists, marks what was actually linked, and turns the catalogs into a way of working.

| | |
| --- | --- |
| Path | Builder |
| Time | About 20 minutes |
| You need | [Prompts and skills](prompts-and-skills.md) |

## What you will be able to do

- Restate the motion stack in one line, and know which words are the post's.
- Find a named repo in the list without pretending every shortened link was resolved.
- Pick one engine, one skill, and one reference, then stop adding tools.

## The stack in one line

[@N01ennn](https://x.com/N01ennn/status/2108182955671580771) summarizes the motion list as: a model writes the code, a skill sets the timing and the camera, an engine renders the MP4 (per post). The post names the model as Opus 5.5 and says the list was posted by Netflix engineers. Both of those attributions are the post's. This guide has not verified them.

The established pattern underneath the slogan: generation, constraint, and a real renderer are three different jobs. A skill that only contains adjectives ("make it premium") does less than a skill that names duration, easing, and a check against the frames.

> [!WARNING]
> **Check each repository before you install.** That sentence is in the post. Installing a skill pack can execute its setup. Read [the supply-chain notes](../07-security/gateway-and-supply-chain.md) first. The repository this guide links is [github.com/whaleyxbt/claude-motion](https://github.com/whaleyxbt/claude-motion), listed first.

## A way to use a catalog

A catalog is a menu. Installing the menu is how agents get slow and how laptops get untrusted code.

| Step | Do this |
| --- | --- |
| 1 | Name the artifact: a 10-second title card, or one scroll section. |
| 2 | Pick one engine (render path) and one skill (constraints). |
| 3 | Pick one reference from the site list if you need taste, and write down what you are copying: type, motion, or layout. |
| 4 | Read that skill and that repo before the agent runs setup. |
| 5 | Keep the prompt small. Put the procedure in the skill and the reference in a file. |
