The references assume this picture and then push on one part of it: memory that compounds, tools behind a protocol, many agents on one plan, a run that happens somewhere else, a model small enough to sit on the machine. The runtime that holds those parts together is [harness engineering](../01-agent-patterns/harness-engineering.md). The rest of the patterns start in [agent patterns](../01-agent-patterns/index.md).
