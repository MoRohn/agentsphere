# 00 · Foundations

An agent is a system you can sketch on a napkin. This section is that napkin, with the words defined carefully enough to build on.

## Pages

| Page | You leave able to |
| --- | --- |
| [What is an agent](what-is-an-agent.md) | Name the six parts and place a task into them |
| [The agent loop](the-agent-loop.md) | Walk perceive, plan, act, observe, remember, stop |
| [Memory, tools, and planning](memory-tools-planning.md) | Decide where a fact, a side effect, and a plan should live |

The references assume this picture and then push on one part of it: memory that compounds, tools behind a protocol, many agents on one plan, a run that happens somewhere else, a model small enough to sit on the machine. The runtime that holds those parts together is [harness engineering](../01-agent-patterns/harness-engineering.md). The rest of the patterns start in [agent patterns](../01-agent-patterns/index.md).
