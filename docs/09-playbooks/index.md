# 09 · Playbooks

Recipes. Each one assumes you have read the concept page it names. They are synthesis: a way to do the work, not a claim that a source prescribed these exact steps.

| | |
| --- | --- |
| Path | Explorer through power user. Each path ends in one of these. |
| Time | One sitting each |
| You need | The concept page linked from the recipe |

Do them in this order if you are going from beginner to power user. Skip ahead when you already have the artifact in the middle column.

| Order | Playbook | You produce | Read first |
| --- | --- | --- | --- |
| 1 | [Your first agent](first-agent.md) | A one-page agent card and a six-step trace | [The loop](../00-foundations/the-agent-loop.md) |
| 2 | [Research agent](research-agent.md) | A raw/wiki/schema layout and one real page | [Wiki memory](../01-agent-patterns/wiki-memory.md) |
| 3 | [Write a skill](write-a-skill.md) | A reviewable `SKILL.md` for one repeated job | [Prompts and skills](../03-prompting-skills/prompts-and-skills.md) |
| 4 | [Skills and craft](skills-and-craft.md) | One stack, reviewed before install, or a rejection note | [Creative toolkits](../03-prompting-skills/creative-toolkits.md) |
| 5 | [Operate agents](operate-agents.md) | A placement for three real tasks | [Cloud and local](../05-runtime-infra/cloud-and-local.md) |
| 6 | [Review a gateway](review-a-gateway.md) | Use, sandbox only, or do not use | [Gateways](../02-tools-mcp/gateways-and-routing.md) |
